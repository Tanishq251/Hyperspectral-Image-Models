# 🧠 Model Zoo

[← Back to README](../README.md)

---

Models are registered via the `@register_model` decorator in `models/registry.py` and organized by publication year under `models/y2017/` … `models/y2026/`, with shared building blocks in `models/helpers/`. Every model also carries bibliographic metadata (full name, paper title, DOI, official code link, venue, year) in `MODEL_CATALOG`, which backs the `year`/`venue` columns in the complexity table generated by `model_info.py`.

To see every model currently loadable in your environment:

```bash
python main.py --list-models
```

Models that depend on an optional package that isn't installed (see [installation](../README.md#quick-start)) are skipped with a warning rather than breaking the listing.

### Input-size requirements

Most models accept any odd `patch_size`. One does not:

| Model | Requirement | Why |
|---|---|---|
| `GSCViT` | `patch_size` divisible by every `group_spatial_size` entry (4 in the published configs) — so **8, 12, 16, 20, …**, not 11 | Group-wise separable attention partitions each feature map into `gss × gss` groups. Spatial dimensions are preserved through every stage (3×3 convs, stride 1, padding 1), so the input patch must divide evenly. A non-divisible size collapses each stage to a single group and skips the second-level group attention entirely — the model would still produce a number, but it would no longer be GSCViT, so this is rejected rather than silently allowed. |

The default protocol uses `patch_size: 11`, so GSCViT must be run with its own config
(`patch_size: 8` or `12`). Results obtained at a different patch size are not comparable to
the rest of the benchmark and should be reported separately.

> Every entry is a re-implementation or adaptation of the authors' released code, ported to this framework's common `(bands, patch_size, num_classes)` interface. Where an adaptation was necessary (e.g. a TensorFlow original ported to PyTorch, or a custom CUDA kernel replaced with a reference implementation), the deviation is documented in the docstring at the top of that model's source file. Credit for the architectures belongs entirely to their original authors.
